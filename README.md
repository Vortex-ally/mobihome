# mobi Home («Доступний Дім»)

Маркетплейс житла для всіх, зокрема для маломобільних людей: каталог оголошень із характеристиками
доступності (рівні мобільності 1–5, аудит доступності, паспорт доступності PDF), модерація оголошень,
платне розміщення та просування через LiqPay.

## Стек

- Python ≥ 3.10 (розробка — 3.14), Django 5.2, Bootstrap 5.3 (CDN), Pillow, Gunicorn.
- БД: SQLite (розробка, за замовчуванням) або PostgreSQL (production, `DJANGO_DB_ENGINE=postgresql` + `psycopg`).
- Кеш лімітів входу/форм: Redis у production (`DJANGO_REDIS_URL`), локально — пам'ять процесу.
- Оплата: LiqPay API v7, підпис SHA3-256, Sandbox і бойовий режими.

## Можливості

- Каталог із пошуком, фільтрами (місто, ціна, кімнати, площа, тип, рівень доступності, зручності, аудит) і сортуванням.
- Оголошення: створення, **редагування власником** (повторна модерація), фото (головне + до 20 додаткових),
  модерація й фотоперевірка адміністратором, відхилення з коментарем, архівування замість видалення оплачених.
- Публікація: безкоштовна (через модерацію), оплачене розміщення 30 днів, просування ТОП №1 / ТОП №3 /
  активна публікація — лише після підтвердженої оплати, автоматичне завершення.
- Особистий кабінет: оголошення, обране, історія платежів із номерами замовлень і статусами.
- Модерація: черга заявок, обов'язкова причина відхилення, історія (хто/коли/джерело), роль «Модератори»
  з мінімальними правами, онлайн- і виїзні перевірки житла (приватні звіти), Telegram-бот модерації.
- Django Admin: модерація, платежі (лише перегляд + контрольоване закриття перевірки), тарифи, просування.
- Темна тема всього сайту й адмінки, адаптивність 360–1440 px, власні сторінки 403/404/500, `GET /healthz/`.

## Швидкий старт (Linux / macOS)

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # для розробки: DJANGO_DEBUG=True
python manage.py migrate
python manage.py createsuperuser
python manage.py setup_moderators   # група «Модератори»
python manage.py runserver    # http://127.0.0.1:8000/
```

Windows: подвійний клік по `run.bat` (створить venv, встановить залежності, застосує міграції й запустить сервер).

## Тести

```bash
python manage.py test --settings=config.test_settings
```

Тести не звертаються до мережі (відповіді LiqPay імітовано). 4 тести пропускаються, якщо в корені є `.env`
(вони перевіряють запуск без нього); ще 4 — без справжнього Redis: `MOBIHOME_TEST_REDIS_URL=redis://127.0.0.1:6379/15`. Результати — [TEST_REPORT.md](TEST_REPORT.md).

## Логіка статусів аудиту за балами (1–10)

- **9–10** — Ідеально (зелений) · **6–8** — Потребує покращення (жовтий)
- **3–5** — Важкодоступно (червоний) · **1–2** — Недоступно (червоний)

`total_score` — середнє балів (вхід, ліфт, пороги, радіус розвороту).
