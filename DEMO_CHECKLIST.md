## Telegram-бот з demo-базою (реальна перевірка — пройдена, підтверджено замовником 25.11)

Окрема конфігурація `data/demo_telegram_env.sh` (поза Git): demo-база, demo-медіа, платежі вимкнені примусово;
зупиняється, якщо база не demo. Токен і chat ID — лише у `data/demo_telegram.secrets` (права 600, поза Git).

1. BotFather: `/newbot` → токен; `/setprivacy` → бот → **Disable**. Закрита група: додати бота й модераторів, написати повідомлення.
2. Секрети: `cp data/demo_telegram.secrets.example data/demo_telegram.secrets && chmod 600 data/demo_telegram.secrets`, вписати токен.
3. Chat ID групи (від'ємне число): `set -a; . ./data/demo_telegram.secrets; set +a; curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getUpdates" | python3 -m json.tool | grep -A3 '"chat"'` → вписати в `TELEGRAM_MODERATION_CHAT_ID`.
4. Telegram ID модератора (@userinfobot) → `set -a; . ./data/demo_telegram_env.sh; set +a; venv/bin/python manage.py setup_moderators --telegram demo_moder=<ID>`.
5. Перезапустити demo-сервер з Telegram (щоб сайт надсилав заявки): зупинити поточний (`pkill -f "runserver 127.0.0.1:8010"`), потім
   `set -a; . ./data/demo_telegram_env.sh; set +a; venv/bin/python manage.py runserver 127.0.0.1:8010 --noreload`.
6. В іншому терміналі: `set -a; . ./data/demo_telegram_env.sh; set +a; venv/bin/python manage.py telegram_moderation_bot --once`, далі без `--once`.
7. Перевірка: demo_user подає оголошення → повідомлення в групі → «Підтвердити» / «Відхилити» (причина відповіддю) → статус у кабінеті та «Історії модерації» (джерело — Telegram).
